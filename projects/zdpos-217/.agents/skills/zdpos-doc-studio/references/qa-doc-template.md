## 怎麼讀這份文件

每個測試案例（TC）有四段：適用條件、在確認什麼、操作（每步寫「應該看到」）、Pass／Fail。只照操作做、只用 Pass／Fail 判斷。對不上的情況（例如找不到頁面）勾 **Blocked** 或 **N/A** 並寫原因，不要勾 Fail。
